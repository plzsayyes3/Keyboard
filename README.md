# 薙刀式タイピング練習

薙刀式v18トップ版と、BeThirty Ortho向けユーザー配列を切り替えて練習する静的サイトです。

## 起動

Node.js 18以上で、リポジトリ直下から静的サーバーを起動します。例:

```sh
npx serve .
```

表示されたURLをブラウザで開いてください。`file://` 直開きではJSONの読み込みがブラウザに拒否される場合があります。

## 入力モード

- サイト内変換: 通常QWERTYの物理キーを `KeyboardEvent.code` で取得し、薙刀式の単打・センターシフト・同時押しをサイト側でかなに変換します。ノートPC内蔵キーボードと自作キーボードのどちらでも、ブラウザへ同じ物理コードが届く構成なら使えます。
- 変換済み入力: OS/QMK/IMEなどで変換されたかな出力を `beforeinput` から受け取り、課題文字と比較します。

## 配列とレッスン

- `data/layouts/naginata-v18.json`: 大岡俊彦氏の公式v18定義を基にした標準配列。
- `data/layouts/user-current.json`: 提供いただいたBeThirty Ortho設定。レイヤー0はQWERTY保持、薙刀式専用レイヤーは5、HJ/GFのモード切替、QのNG_SHFT、A/Sタップダンスをメタデータとして保持し、かな定義は標準v18を継承します。
- `data/lessons/`: 基礎文字・単語・短文。JSONを追加してレッスンを拡張できます。

複雑な自作キーボードのレイヤー切替自体はOSやQMK側が担当します。このサイトはブラウザに届いた物理キーコードを採点するため、QMK側がレイヤー5を有効にしているかどうかは変更しません。

## 既知の制約

- 公式定義全体の編集モード・IME制御・漢字変換は対象外です。
- 現在の標準JSONは練習MVP向けに主要な清音・濁音・半濁音・拗音を収録しています。今後、公式定義ファイルの全組合せを機械的に取り込む余地があります。
- ブラウザの `KeyboardEvent` はキーボードの同時押し性能やOSのキーリピート設定の影響を受けます。
